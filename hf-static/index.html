A character guessing game

Think of a character.
Let's find them.

From anime and manga to games, comics, movies and TV. Give Nekomimi a clue, answer its questions, and watch the possibilities narrow.

Launch on Colab ↗ Run locally ↗

This Space is the project showcase. Open Colab or run locally to play the full game.

01 / THE CLUE

Start with what you know

A series, a distinctive outfit, a personality trait. A little detail helps the search find the right cast.

02 / THE QUESTIONS

Narrow the possibilities

Answer yes/no and multiple-choice questions, or add another detail as Nekomimi explores candidates.

03 / THE GUESS

Find your character

The Laya decision model evaluates the evidence. Online sources supply candidates; Laya helps decide which fits.

Your first round

  1. Open the Colab notebook and select an L4 runtime. GPU availability depends on your Colab plan.
  2. Add your NGROK_TOKEN in Colab's secrets sidebar, then run the notebook cells from the top.
  3. Open the public /nekomimi link printed by the server cell and think of a character.

The notebook's public link has no login. Optional Google API features can bill your key. See the setup guide before enabling them.
